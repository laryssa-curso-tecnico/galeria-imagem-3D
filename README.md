# Galeria de Imagem 3D

A Galeria de Imagem 3D é uma página interativa que apresenta diferentes tipos de carros em uma galeria com efeito tridimensional.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
